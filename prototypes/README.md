- **Written by:** Prototype brief agent (brief), Builder agent (code), Findings agent (findings)
- **Templates:** [templates/prototype-brief.md](../templates/prototype-brief.md), [templates/prototype-findings.md](../templates/prototype-findings.md)
- **Read by:** Builder, Findings, Spec writer
