# Agents

One role file per agent. Each file states the agent's single job, what it reads, what it writes, its template and its definition of done.

- **Naming:** the agent name in lowercase with hyphens, for example `intake.md`, `radar-sweeper.md`
- **Template:** [templates/agent-role.md](../templates/agent-role.md)

Agents are added from build step 2 onwards.
