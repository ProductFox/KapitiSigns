# Hypothesis tags

The approved tags for hypotheses. The Digest agent matches radar changes to hypotheses using these tags, so they must be spelt the same way every time.

## Rules

- Tags are lowercase with hyphens, for example `aged-care`.
- Agents use approved tags only. If none fits, the agent adds a suggestion under "Proposed".
- Only the product owner approves a tag. To approve one, move it from "Proposed" into its section, or ask Claude to.
