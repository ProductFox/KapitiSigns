# Specs

One subfolder per hypothesis that has passed prototyping.

- **Naming:** `HYP-001/spec.md`. Slices may get their own files in the same subfolder later.
- **Written by:** Spec writer agent. The Spec reviewer and Feasibility agents add notes to the same file.
- **Template:** [templates/spec.md](../templates/spec.md)
- **Read by:** Engineering agents, the product owner

The product owner signs off every spec. Agents never do.
