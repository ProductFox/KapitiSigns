# Discovery

One discovery brief per hypothesis.

- **Naming:** `HYP-001-brief.md`
- **Written by:** Researcher agent. The Critic agent adds its challenge section to the same file.
- **Template:** [templates/discovery-brief.md](../templates/discovery-brief.md)
- **Read by:** Critic, Decision pack, Delivery risk

Every finding needs a source and a confidence rating: strong, weak or unknown.
