# Changes

One change list per radar sweep. Each list holds only what changed since the last sweep.

- **Naming:** the sweep date, for example `2026-11-16.md`
- **Written by:** Radar sweeper agent
- **Template:** [templates/change-list.md](../../templates/change-list.md)
- **Read by:** Digest agent

Every change must have a source link and the date it was found. The Digest agent rejects any change without one.
