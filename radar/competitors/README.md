# Competitors

One file per competitor.

- **Naming:** the competitor's name in lowercase with hyphens, for example `acme-health.md`
- **Written by:** Radar sweeper agent (updates), Researcher (new competitors found during discovery)
- **Template:** [templates/competitor.md](../../templates/competitor.md)
- **Read by:** Radar sweeper, Researcher, Decision pack

Every evidence item must have a source and a date.

Organisations that must never be treated as competitors are listed in [excluded.md](excluded.md).
